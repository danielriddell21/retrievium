# Examples

Runnable examples for every searching algorithm in retrievium.

```sh
go run examples/<name>/main.go
```

## searches

| Example | Algorithm | Scenario |
|---|---|---|
| [`linear_log_scanner`](linear_log_scanner/main.go) | LinearSearcher | Scan an unsorted application log for HTTP error codes |
| [`binary_version_lookup`](binary_version_lookup/main.go) | BinarySearcher | Look up a software version in a sorted release registry |
