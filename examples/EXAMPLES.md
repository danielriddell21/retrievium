# Examples

Runnable examples for every searching algorithm in retrievium.

```sh
go run examples/<name>/main.go
```

## searches

| Example | Algorithm | Scenario |
|---|---|---|
| [`linear_log_scanner`](linear_log_scanner/main.go) | LinearSearcher | Scan an unsorted application log for HTTP error codes |
| [`binary_version_lookup`](binary_version_lookup/main.go) | BinarySearcher | Look up a software version in a sorted release registry |
| [`ternary_salary_band`](ternary_salary_band/main.go) | TernarySearcher | Locate an employee's salary in a sorted pay scale |
| [`fibonacci_library_catalogue`](fibonacci_library_catalogue/main.go) | FibonacciSearcher | Find a book by Dewey decimal call number in a sorted catalogue |
| [`jump_sensor_reading`](jump_sensor_reading/main.go) | JumpSearcher | Find a temperature reading in a sorted sensor log |
